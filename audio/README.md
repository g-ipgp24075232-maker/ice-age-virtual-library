# MP3 untuk Dengar Cerita

Simpan fail MP3 yang ingin dimainkan oleh murid dalam folder ini, contohnya:

- audio/buku-1.mp3
- audio/buku-2-halaman-1.mp3

Dalam panel **Guru → Buku → Audio Dengar Cerita**, masukkan URL relatif `audio/buku-1.mp3`, kemudian klik **Simpan URL MP3**.

Fail MP3 dalam folder ini akan disertakan dalam GitHub Pages semasa deploy. Gunakan nama fail ringkas, huruf kecil, tanda sempang dan sambungan .mp3.

**Penting:** Mengubah fail dalam GitHub perlu Commit; memasukkan URL dalam Guru akan disimpan sebagai draf setempat sehingga penerbitan JSON.
