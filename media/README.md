# Media buku — Perpustakaan Maya Zaman Air Batu

Letakkan **fail gambar, GIF dan video asal** yang dieksport daripada panel Guru ke folder ini.

1. Di laman web, pilih **Guru → Buku → Halaman → + Gambar atau + Video** dan muat naik fail daripada peranti.
2. Selepas membuat perubahan, pilih **Eksport JSON / ZIP Media**.
3. Nyahzip pakej, kemudian muat naik setiap fail dalam folder `media/` pakej ke folder GitHub `media/` ini. Kekalkan **nama fail asal daripada pakej**.
4. Gantikan fail `published-content.json` di akar repositori dengan kandungan JSON yang dieksport, lalu **Commit changes**.
5. Tunggu GitHub Pages **Success**; murid di peranti lain akan melihat media tersebut.

Upload media terus dalam pelayar tidak menetapkan had MB buatan. Namun kapasiti peranti, kuota pelayar, had GitHub dan kesesuaian format video pada pelayar masih terpakai. Jika fail terlalu besar untuk Github Pages, gunakan URL video yang dihoskan sebagai pilihan tambahan.

**Jangan hanya upload JSON:** fail media fizikal mesti disertakan untuk dilihat murid lain.
