# ❄️ Perpustakaan Maya Zaman Air Batu — Jelajah Dunia Ais

A standalone interactive Bahasa Melayu virtual library for Malaysian Year 4 History.

## Available in the GitHub version

- Colorful ice cave bookshelf with **six books**.
- Page navigation by buttons, keyboard arrows, or touch swipe.
- Text-to-speech via the browser's Malay voice (when available).
- Interactive multiple-choice questions with immediate feedback.
- Teacher editor: add, duplicate or remove books and pages; edit text, image/video URLs, and quiz blocks.
- Browser-local draft saving and JSON import/export.
- Editable resource placeholders with 5K evaluation guidance.
- Static deployment workflow in `.github/workflows/pages.yml`.

## Open and publish

Open `index.html` in a modern browser. To publish through GitHub Pages, open **Settings → Pages → Build and deployment → GitHub Actions**. When deployment has succeeded, the expected site address is:

https://g-ipgp24075232-maker.github.io/ice-age-virtual-library/

## Teacher editing / Cara sunting

Open **✏️ Guru**, select a book and page, make changes, then press **💾 Simpan draf**. This only saves in the current browser. Press **⬇ Eksport JSON** to back up content, and **⬆ Import JSON** to restore it. Changing exported JSON does **not** automatically publish to the live website; source edits and another GitHub commit are required.

## Project scope and transparency

This is a functional **standalone initial release**, not the complete React/TypeScript/Vite project prepared separately in the conversation ZIP. Full webcam gesture tracking, file-based publishing of browser edits, all requested multimedia block types, live browser QA, verified historical references, and the comprehensive content management system are **not yet integrated** in this GitHub repository. No webcam is activated in this release. Do not treat historical resource placeholders as verified citations.

## Pusat e-Sumber

Teachers should evaluate sources with 5K: **Kredibiliti, Ketepatan, Konteks, Kesepadanan, Keselamatan**. Institutional names are suggestions for further verification.
